# A1 Wortschatz

Офлайн-тренажёр слов Goethe-Zertifikat A1 (Start Deutsch 1) для телефона. PWA: открыть в Chrome → «Установить приложение».

- 792 слова с переводами, 18 тематических разделов
- Интервальные повторения FSRS-5, карточки, письмо RU↔DE, артикли, мн. число, пропуск в примере, диктант, пары
- Прогресс хранится на устройстве (IndexedDB) и не теряется при обновлениях

## Обновление
Правки в `src/app.html` или `data/*.txt` (`раздел|слово|мн.ч.|перевод|пример с [словом]`), затем `python3 build.py` и push.
ID слова = немецкая запись; при переименовании добавьте старый ID в `ALIASES` в `src/app.html`, чтобы прогресс переехал.
